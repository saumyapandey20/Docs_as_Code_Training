# Installation
 
This guide explains how to install the product.
 
## Prerequisites
 
Ensure that your system meets the following requirements:

| Requirement | Minimum specification | Recommended specification |
|---|---|---|
| Operating system | Windows 10 | Windows 11 |
| Memory | 4 GB RAM | 8 GB RAM |
| Disk space | 2 GB | 5 GB |
| Web browser | Microsoft Edge | Latest version of Microsoft Edge |
| User permissions | Standard user | Administrator |

You must also have:

- A valid SampleApp license
- Access to the installation package
- Administrator permissions
- An active internet connection

>[!NOTE]
>If you do not have administrator permissions, contact your system administrator.

 
## Install the product
 
1. Download the installation package.
2. Open the downloaded file.
3. Follow the installation wizard.
4. Select **Install**.
5. Select **Finish** when the installation is complete.
 
## Verify the installation
 
Open the application and sign in using your account.
 
## Next steps
 
After installation, continue with the [Getting Started](getting-started.md) guide.
